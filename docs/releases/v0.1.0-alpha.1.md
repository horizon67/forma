# Forma v0.1.0-alpha.1

This is Forma's first public alpha and an intentionally unstable pre-release.
Language, artifact, and CLI compatibility may change in later alpha versions.

## Included

- the deterministic Forma front-end and the bounded language described by the
  [alpha profile](https://github.com/horizon67/forma/blob/v0.1.0-alpha.1/docs/alpha-language-profile.md), through named Action
  Precondition;
- `authoring-context`, `check`, `resolve`, four read-only projections,
  `request`, `verify`, and the thin Codex-backed `generate` command;
- a complete project/task quickstart and email-verified membership example;
- macOS and Linux binaries for amd64 and arm64, plus `SHA256SUMS`.

The released archives contain one `forma` executable. The release workflow
builds them with the tag embedded, verifies clean source installation on macOS
and Linux, and checks that the tag, binary version, authoring profile, install
command, and release notes agree.

## AI generation boundary

The reference path uses an independently authenticated Codex CLI. The recorded
dogfood used `codex-cli 0.144.4`; that observation is evidence, not a promise
that Forma controls Codex CLI compatibility. `forma generate` stops for human
diff review and never executes generated application code on the host.

## Known limitations

- Use the thin runner only with a fresh or otherwise user-owned, trusted
  repository.
- Human review remains mandatory. Generated code and tests can contain defects
  even when Codex reports success.
- Deletion policy for required relations is not defined by the alpha language.
- Multiple assignment, collection mutation, record creation, Derived Value,
  Occurrence, Effect, `fmt`, `explain`, LSP, and multiple AI providers are not
  included.
- Windows binaries and stable compatibility guarantees are not included.

See the [end-to-end quickstart](https://github.com/horizon67/forma/blob/v0.1.0-alpha.1/docs/quickstart.md),
[installation guide](https://github.com/horizon67/forma/blob/v0.1.0-alpha.1/docs/install.md), and
[security boundary](https://github.com/horizon67/forma/blob/v0.1.0-alpha.1/docs/security.md)
before using `generate`.
